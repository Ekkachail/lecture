## ใช้งานสไลด์

| ปุ่ม | ทำอะไร |
|---|---|
| `→` `Space` `PageDown` / ปัดซ้าย | สไลด์ถัดไป |
| `←` `PageUp` / ปัดขวา | สไลด์ก่อนหน้า |
| `Home` / `End` | สไลด์แรก / สุดท้าย |
| `N` | เปิด-ปิดโน้ตผู้บรรยาย |
| `F` | เต็มจอ |

ลิงก์ตรงไปสไลด์ที่ต้องการได้ด้วย `#s` ตามด้วยเลขสไลด์ เช่น `…/index.html#s4` คือหน้าโหลดเอกสาร

## ไฟล์ในแฟ้มนี้

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | สไลด์ทั้งหมด (โลโก้และ QR ฝังอยู่ในไฟล์แล้ว) |
| `fonts/` | ฟอนต์ Kanit และ Sarabun ที่สไลด์ใช้ — ไม่ต้องพึ่ง Google Fonts หน้าตาจึงไม่เปลี่ยน |
| `fonts/OFL.txt` | สัญญาอนุญาตของฟอนต์ (SIL Open Font License) ต้องแนบไปพร้อมฟอนต์ |
| `icon.png` | ไอคอนบนแท็บเบราว์เซอร์ |
| `slides.pdf` | สไลด์ฉบับ PDF สำหรับโหลด |

## วิธีแขวนบน GitHub Pages

1. สร้าง repository ใหม่บน GitHub ตั้งเป็น **Public**
2. กด **Add file ▸ Upload files** แล้วลากไฟล์ทั้งหมดในแฟ้มนี้ลงไป (รวมโฟลเดอร์ `fonts`) ▸ **Commit changes**
3. ไปที่ **Settings ▸ Pages** ช่อง Source เลือก **Deploy from a branch** ▸ Branch **main** / **(root)** ▸ **Save**
4. รอประมาณ 1–2 นาที หน้าเว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

แก้สไลด์ภายหลัง: อัปโหลด `index.html` ตัวใหม่ทับตัวเดิม ลิงก์เว็บจะคงเดิม

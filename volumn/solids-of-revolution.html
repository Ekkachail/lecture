DISK & WASHER · ตั้งฉากกับแกน

ตัดพื้นที่ด้วยแถบที่ ตั้งฉาก กับแกนหมุน แถบหนา Δ จะกวาดเป็นแผ่นกลมตัน (จาน) หรือแผ่นกลมที่มีรูตรงกลาง (วงแหวน)

V = π ∫ₐᵇ [ R(x)² − r(x)² ] dx
  • R = ระยะจากแกนถึงขอบที่ ไกล กว่า
  • r = ระยะจากแกนถึงขอบที่ ใกล้ กว่า
  • ถ้าแกนหมุนผ่านกลางพื้นที่ จะได้ r = 0 คือจานตัน
  • หมุนรอบแกนนอน y = c → ปริพันธ์เทียบ dx; หมุนรอบแกนตั้ง x = c → ปริพันธ์เทียบ dy

CYLINDRICAL SHELLS · ขนานกับแกน

ตัดพื้นที่ด้วยแถบที่ ขนาน กับแกนหมุน แถบจะกวาดเป็นผิวทรงกระบอกบาง ๆ คลี่ออกได้เป็นแผ่นสี่เหลี่ยม กว้าง 2πr สูง h หนา Δ

V = 2π ∫ₐᵇ r(x) · h(x) dx
  • r = ระยะจากแกนหมุนถึงแถบ
  • h = ความสูงของแถบ = |f − g|
  • เหมาะเมื่อหมุนรอบแกนตั้งแต่ฟังก์ชันเขียนในรูป y = f(x) — ไม่ต้องแก้สมการกลับเป็น x = f⁻¹(y)

RULE OF THUMB

ดูว่าแถบตัดขวางวางตัวอย่างไรเทียบกับแกนหมุน แล้วเลือกวิธีที่ทำให้ ไม่ต้องแก้สมการกลับ และ ไม่ต้องแบ่งปริพันธ์หลายช่วง

  • y = f(x) หมุนรอบแกนนอน → จานหมุน (dx)
  • y = f(x) หมุนรอบแกนตั้ง → เปลือก (dx)
  • x = g(y) หมุนรอบแกนตั้ง → จานหมุน (dy)
  • x = g(y) หมุนรอบแกนนอน → เปลือก (dy)

ทั้งสองวิธีต้องให้คำตอบเท่ากันเสมอ ลองสลับแท็บดูค่าปริมาตรเทียบกัน
